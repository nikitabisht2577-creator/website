# cookie Landing Page
A Simple and responsive cookie shop landing page built using HTML , CSS.

## Features
-Beautiful navigation bar
-Hero section with background image
-currently serving products section
-order Now buttons
-customer testimonial section
-Bestseller section
-Image gallery
-Social media icons using Remix Icons

## Technologies Used
-HTML5
-CSS
Remix Icons

## How to run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
